## 1. Environment facts that will otherwise cost you an hour each

- **Toolchain:** Node 24, pnpm 11.
  - `pnpm verify` = typecheck + unit/contract tests + production build.
  - `pnpm test:browser` = Playwright/Chromium, about 600 specs, 30-80 minutes.
  - `pnpm verify:sql` = PostgreSQL with pgTAP.
- **Git LFS content is not in a fresh checkout.** Every PNG under `public/assets/`,
  `public/game-content/` and `assets/`, and every `.blend`, is a ~131-byte pointer.
  - Fetch it with `bash scripts/provision-git-lfs.sh && git lfs pull`. Bandwidth is
    metered.
  - Without it, `pnpm verify:assets` refuses correctly, and so do the browser specs that
    decode art: `actor-*`, `environment-art`, and *"the art is real image data"*.
    Ignore only those locally.
- **Blender:**
  - The pin is **Blender 5.2** (`tooling/blender/pipeline_common.py`,
    `SUPPORTED_BLENDER_VERSION = (5, 2)`). Every script refuses another version.
    `LOCKSTATE_ALLOW_BLENDER_MISMATCH=1` exists for investigation only, and its output
    must never be committed.
  - Always run `--background --factory-startup`.
  - Blender needs `libegl1` and `libegl-mesa0` even headless. On llvmpipe, a 256x512
    frame takes about 50 s.
  - CI does not have Blender, so rendering happens on your machine and the rendered PNGs
    are committed through LFS.
- **Worktrees:** pnpm refuses a symlinked `node_modules` in a git worktree. In a
  worktree, run the tools directly:
  - `npx tsc -b && npx tsc -b tsconfig.tools.json`
  - `npx vitest run`
  - `node scripts/cloudflare-task.mjs build production`
  - `npx playwright test -c tests/browser/playwright.config.ts <files>`, with a unique
    `LOCKSTATE_BROWSER_TEST_PORT` per concurrent run. `pnpm test:browser -- -g` does
    **not** filter by title.
- **CI is self-hosted** and every `runs-on:` is the bare `self-hosted` selector.
  - Since 2026-09-23 the pool includes slower hosts. There, `browser` takes 1.2-1.4 h
    against a 90-minute job cap, and the 5 s default Vitest timeout has been hit by
    heavy deterministic tests.
  - Give such a test an explicit per-test budget with a measured comment. See
    `tests/determinism/job-performing-restart-bound.test.ts`.
  - **Never raise a timeout to hide a race, skip a test, or weaken an assertion.**
- **`docs/adr/STATUS-QUEUE.md` carries an anchor with a 10-merge staleness budget.**
  Count it before merging:
  `git log --first-parent --oneline <anchor>..origin/main | grep -v "chore(release)"`.
  - When it reaches ten, the foundation gate goes red on every branch at once.
  - Re-anchor before that. **Never raise `ANCHOR_STALENESS_BUDGET_MERGES`.**
  - It stood at 8 of 10 on 2026-09-23.
- **ADR numbers are assigned centrally.** 0124 went to #540 (prisoner priors) and 0125
  to #985 (refusals in history). Both are still in flight. The next free number is
  **0126**.

## 3. The Blender remodel: the map

### 3.1 What exists

**Actors** (`assets/source/blender/actor.{prisoner,guard,cook,medic,staff}.base.blend`):
- Each scene has a `Camera` with the fixed isometric framing, a `SpriteTarget` at the
  foot, and a `SpriteRoot` parent facing south at zero rotation.
- Frames 1-8 are the walk cycle; frame 1 is also idle. There is no opaque backdrop.
- `tooling/blender/export-directional-sprites.py` renders 8 facings.
- `tooling/blender/pack-sprite-atlas.py` packs them into `public/assets/actors/`, one PNG
  per clip plus `<asset-id>.atlas-manifests.json` and `asset-registry.json`, against
  `assets/contracts/character-8-direction.contract.json` and
  `assets/contracts/runtime-atlas-manifest.schema.json`.
- `tooling/blender/create-prisoner-base.py` and `build-prisoner-base.ps1` generate the
  prisoner base.

**Environment** (`assets/source/blender/environment.mvp.catalog.blend`, 23 entries,
manifest beside it):
- Generated by `tooling/blender/create-environment-catalog.py`.
- Rendered **orthographically, straight down**, on transparent film, by
  `tooling/blender/render-environment-objects.py` into `assets/rendered/environment/`.
  The command is in `docs/ART_PIPELINE.md` §"Environment objects".
- Published by `pnpm content:rendered-art` (`tooling/build-rendered-art-catalog.mjs`)
  to `public/game-content/rendered-art.v1.json`, with content-hashed files under
  `public/game-content/source-art/` (ADR 0100).

**Runtime wiring:**
- Sprite definitions: `src/rendering/assets/environment-sprites.ts`.
- Catalogued object to sprite: `SPRITE_BY_OBJECT_ID` in
  `src/rendering/world/environment-art.ts`.
- Objects and footprints: `src/content/object-catalog.ts`.

### 3.3 Rules the remodel must keep: rulings and mechanics

1. **A generated image is a concept reference to model from, never a shipped sprite.**
   This was the owner's ruling on 2026-09-13.
   - The Blender renderer satisfies the two footprint-aspect checks in
     `tests/unit/environment-art.test.ts` *by construction* (drift 0), and a generated
     image satisfies them only by luck.
   - A pinned render can be reproduced byte for byte; a generated image cannot.
   - The prompts are in `docs/ART_CONCEPT_PROMPTS.md`, with invariants taken from the
     renderer: the two sun angles and the tile scale. Changing this rule is an ADR, not
     a prompt.
2. **Style is the 2026-09-13 identity delivery.** The reference is `docs/design/2026-09-13-identity-v5/`,
   including the world illustration. The delivery is vendored read-only; do not edit it.
   `docs/VISUAL_IDENTITY.md` says what binds.
3. **Every object frame carries its declared footprint aspect exactly.** Model to the
   footprint in `object-catalog.ts`. Do not change footprints to suit art: footprints
   are simulation content.
4. **Actors keep the 8-direction contract**: direction order, frames per clip, frame
   size, 2-px extrusion gutters, foot pivot, and atlas size limits. `pnpm verify:assets`
   enforces it. Changing the contract is an ADR.
5. **Determinism.** `tooling/verify-pipeline-determinism.mjs` must pass: two runs, the
   same bytes. `tooling/blender/scene-fingerprint.py` fingerprints generated scenes.
   Keep to the four fixes recorded in `docs/ART_PIPELINE.md` §"Reproducibility".
6. **Legibility is judged on screen, in a built prison, at zoom 1 and zoom 3.** It is
   not judged at 256x256 in isolation. That bar refused two renders already.
7. **Two things are blocked in code, not art. Fix the code first, then the art has
   somewhere to go.**
   - A terrain floor: `SparseWorld.setTerrain` has no caller.
   - A second wall or door kind: the edge writer defines exactly two edge values.
   - Both are ordinary engineering inside your mandate. Read
     `docs/ARCHITECTURE.md`, `docs/WORLD.md` and `docs/RENDERING.md` first, and write
     an ADR if the decision is not already in one.

### 3.4 The one owner gate every art batch passes through

The `browser` job in `.github/workflows/ci.yml` fetches art with `git lfs pull
--include=…`. **For environment art, that is a literal list of glob segments, one per
sprite id**, not a pattern.
- The decode step beside it fails closed on any published sprite whose bytes are a
  pointer.
- **Re-rendering an id already on the list needs no release.** The segment globs over
  the content hash.
- **A new id needs its segment added**, and `ci.yml` is owner-reserved.
- Actors are fetched with the directory include `public/assets/actors`, so remodelled
  actors with the same ids need no release.

The owner ruled on 2026-09-21 *"Jedna prośba na partię"*: one release request per batch.
This is `AGENTS.md`, "Instructions recorded…", entry 9. So:
1. Group new ids into a batch.
2. Compute the exact segment text as the research doc §5 does.
3. Put it to the owner as one clickable question.
4. Record their answer in `AGENTS.md`'s reservation 3 entry, dated, in their words.
5. Only then edit that one line.

**Never edit any other part of `ci.yml`, `deploy.yml`, `wrangler.jsonc` or
`public/_headers`.**

## 4. How this repository expects you to work

- **Issues and PRs:** one issue, one small reviewable PR. Reference the issue in every
  commit. Follow the PR template if there is one.
- **Red before green:** a new test proves nothing until you have seen it fail against
  mutated production code. Say in the PR that you did.
- **Report honestly.** A failing test is reported with its output. A skipped step is
  reported as skipped. "Flake" is not a root cause.
- **Architecture:** when a change touches simulation determinism, persistence format,
  worker boundaries, rendering architecture, security or deployment, read the relevant
  `docs/*.md` and ADR first. If the decision is absent, write an ADR (next free: 0126)
  rather than deciding it silently in code.
- **Merging:** the owner allowed merging green, conflict-free PRs ("Scalaj sam
  zielone", 2026-09-23). Green means `verify`, `assets` and `browser` all pass on the
  head. If a tool or policy blocks a merge, tell the owner. Never route around it.
- **Language:** the owner prefers decisions laid out as clickable options, written in
  Polish, with a recommended option marked *(zalecane)* and each option's measured
  consequence.
