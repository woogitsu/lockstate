# Outdoor steel bench variant for the Yard

This is a visual variant of the existing `object.bench`, not another buildable. The current indoor catalog has a bench module from the shared environment source. The Yard needs its own weatherproof appearance if that same object is placed outdoors; its price, footprint, capabilities and save identity stay those of `object.bench`. The initial art commit was separate from the contextual runtime selector; the latter is described below.

The [twelve-pose contact sheet](poses.png) contains actual SHA-checked Blender frames at four yaw angles and three elevations. Powder-coated petrol steel supports three sealed timber seat planks, two back slats, rounded arm ends, visible stainless fixings and rubber anchors. The subdued palette matches the new outdoor exercise station without copying its geometry. Source: `assets/source/blender/furniture.yard.steel-bench.blend`; asset ID: `furniture.yard.steel-bench`.

The evaluated mesh bounds including modifiers are **X [0.11,1.89], Y [0.12,0.86], Z [0,1.05]**, in minimum-corner coordinates of a 2×1 occupied-square footprint. The source camera and catalog target are both `[1,0.5,0.52]`. The renderer exports 12 yaw × 6 elevation poses at 256×256; orthographic span is exactly 4 world tiles, so `256/4 = nominalPixelsPerTile 64`. Runtime image scale `TILE_SIZE_PX/64` preserves world size. The exporter strips Blender's volatile PNG timestamps and checks the transparent image border before writing SHA-named poses and `public/game-content/oblique-furniture.yard-steel-bench.v1.json`.

Rebuild the source with `tooling/blender/create-yard-steel-bench.py`, export poses with `tooling/blender/render-yard-steel-bench-oblique.py`, and recreate the contact sheet with `python tooling/research/yard-steel-bench-contact-sheet.py`. The focused catalog test verifies the source SHA, all 72 frame SHAs and the exact resolution/camera-scale/nominal-size equation. This draft alone does not prove browser placement or save/load.
