## 4. Two measured constraints worth planning around

**CI is the bottleneck, not agent count.** Ten agents filled the queue to 17 runs
against a pool running two at a time, with `browser` at 25-45 minutes. Past that point
more agents lengthen the queue rather than the throughput. Merging green pull requests
is worth more than starting new branches.

**Ten parallel agents exhausted the session limit in roughly two hours.** Merging
survives it — those are tool calls, not model calls — so a limited session can still
clear the backlog.

## 5. One defect worth remembering

#1291's red `browser` was real and its own: the previous repair was too **wide**. The
comment beside the code claimed `"place"` *"stays the same length as the word it
replaces"* — "bed" is three characters, "place" is five. A false sentence beside the
code it describes made a widening look free, and it broke two layout specs. Fixed in
the wording, not the assertions. `docs/AGENT_WORKFLOW.md` §4, exactly.
