# Lockstate design direction

Private, standalone interactive visual prototype and design book based on a scoped review of woogitsu/lockstate. The original game repository was not modified.

Entrypoint: dist/index.html. No build or dependencies are required. Deployment uses Sites static hosting.

The prototype contains sample data and a generated raster map, not the Phaser simulation. Local save uses a separate localStorage key, lockstate-design-v1; it does not read game saves.

Design specification and product constitution are available inside the design book and as Markdown downloads in dist/.

Source art: built-in image generation, 1536×1024. The pre-redesign screenshot was read from the user's private repository and this Site must remain private unless the user authorizes wider access.
