## 6. Operational lessons this session paid for

- **Push every measurement as you get it.** The container died **four times**.
  Agents that pushed lost nothing; one that held its work lost hours of
  browser measurement.
- **Run browser specs through the suite runner**, never `playwright test`
  directly: `LOCKSTATE_BROWSER_TEST_PORT=NNNN node
  --experimental-transform-types tests/browser/run-suite.ts --suite browser`.
  A direct invocation fails every test with `Cannot navigate to invalid URL`,
  because the runner is what starts the dev server and sets `baseURL`.
- **Give every agent a distinct `LOCKSTATE_BROWSER_TEST_PORT`.** Two suites on
  5183 made one read the other's worktree and produce scattered false reds.
- **Never `pkill` by pattern.** One agent ran `pkill -f headless_shell` against
  the shared process table and disrupted two others. Kill your own by pid.
- **`scrollIntoView` scrolls an `overflow: hidden` box.** Programmatic
  scrolling is not the affordance a player has, so a reachability sweep that
  scrolls before hit-testing certifies a panel no finger can reach. Proved:
  flipping `.ui-panel.hud-staff` to `hidden` left 13 of 14 specs green.
  **`app-shell.spec.ts`'s `controlReachability` still inherits this hole.**
- **`worktree/node_modules` is a symlink**, so `pnpm install` refuses with
  `ERR_PNPM_UNSAFE_MODULES_DIR`. Run tools directly from
  `/workspace/lockstate/node_modules/.bin/`.
- **The STATUS-QUEUE anchor fires every ~10 releases** at this merge cadence.
  The fix is the **re-read**, never the budget constant. The last pass checked
  95 claims and found 32 drifted — **eleven of them stale before its window**,
  which no diff could have found, and two of those were wrong *when the
  previous pass certified them*.
