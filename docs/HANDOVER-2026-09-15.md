## 5. What the two sessions paid to learn

The first four are the previous session's and are reproduced because they cost
it something. The rest are this morning's.

- **Push every measurement as you get it.** The container died **four times**.
  Agents that pushed lost nothing; one that held its work lost hours of browser
  measurement.
- **Run browser specs through the suite runner**, never `playwright test`
  directly: `LOCKSTATE_BROWSER_TEST_PORT=NNNN node
  --experimental-transform-types tests/browser/run-suite.ts --suite browser`. A
  direct invocation fails every test with `Cannot navigate to invalid URL`,
  because the runner is what starts the dev server and sets `baseURL`.
- **Give every agent a distinct `LOCKSTATE_BROWSER_TEST_PORT`**, and **never
  `pkill` by pattern** — one agent's `pkill -f headless_shell` ran against the
  shared process table and disrupted two others.
- **`worktree/node_modules` is a symlink**, so `pnpm install` refuses with
  `ERR_PNPM_UNSAFE_MODULES_DIR`. Run tools directly from
  `/workspace/lockstate/node_modules/.bin/`.
- **`scrollIntoView` scrolls an `overflow: hidden` box — and it scrolls the
  window too.** `src/styles.css:6` makes the page itself a hidden box, so a
  sweep that scrolled before hit-testing was also defeating its own
  *"a control pushed off the edge reports here"* claim. Closed in #1204; the
  evidence is the control run, not the green one.
- **A green run proves nothing about an instrument you just tightened.** Both
  halves of #1204 are argued from a mutation that the old instrument passed and
  the new one failed. A tightened check that finds nothing has to show what it
  would have found.
- **The delta method's blind spot is not a footnote.** The re-anchor's
  intersection was 21 files; **23 of its 30 findings were outside it**, already
  wrong before the window opened, on files no diff would have raised. Reading a
  file's own sections against each other — one minute of work — found a split
  that no diff could.
- **An offset applied to a wrong number returns a wrong number.**
  `regime-panel.ts:738` was recorded as `:730` *"moved by eight"*; the file goes
  728 → 736 → 741 and never passes through 738.
- **Brief your agents with the window and let them refute you.** All three
  verification agents on the re-anchor corrected the brief they were given, and
  two of the corrections changed what got written.
