# Interior wall cap, visual revision 1

`interior-wall-cap-multiview-v1.png` is an original four-view concept generated on 2026-09-24 with OpenAI image generation. The views show an overhead strip, frontal face, end section, and oblique angle. The overhead view guides the pale enamel coping, two continuous dark edge seams, and small metal anchors.

The playable sprite is modeled in Blender as `wall.interior.cap.overhead` in `environment.mvp.catalog.blend`; the concept image is reference only. Its 1 × 0.25 tile render deliberately uses zero transparent margin, so repeated wall segments meet at their borders without gaps. The existing frontal wall sheet remains the source of the wall face. This changes appearance only, not wall geometry or simulation rules.
