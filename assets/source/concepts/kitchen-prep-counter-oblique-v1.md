# Kitchen prep counter oblique module

`object.prep-counter` is a two-tile by one-tile food-preparation workstation. The
procedural Blender source builds a stainless cabinet, wood butcher-block worktop,
inset basin, three ingredient pans, front drawers and sanitation indicator. The
fixed 12 yaw × 6 elevation camera set produces 72 transparent RGBA frames at
128 px, using the same footprint and front-facing convention as the kitchen
stove and fridge modules.

The source script is `assets/source/blender/scripts/build_kitchen_prep_counter.py`.
Rerunning it regenerates the `.blend`, all frames and manifest hashes.
