# Medicine cabinet, visual revision 1

`medicine-cabinet-multiview-v1.png` is an original four-view reference for
Lockstate's infirmary. The square cream lid and teal cross remain readable from
overhead; the other views guide the enamel doors, locks, hinges and short feet.

The shipped image is rendered from the 1 × 1 tile
`furniture.medical.cabinet` collection in `environment.mvp.catalog.blend`.
The reference image itself is never a runtime sprite. The game uses the render
for `object.medicine-cabinet` without changing its construction or supply rules.
