# Washing machine oblique asset

- **Consumer:** `object.washing-machine` (`2×1` footprint, `laundry` capability) in the default object catalog.
- **Asset id:** `utility.washing-machine.variants`.
- **Source:** `assets/source/blender/utility.washing-machine.variants.blend` generated by `assets/source/blender/scripts/build_washing_machine.py`.
- **Render contract:** 128×128 transparent PNGs, 12 yaw samples (30°) × 6 elevations (20°–70°), pivot `(64,64)`, orthographic camera.

The model uses a compact enamel cabinet, front glass drum, control strip, status light, and feet so the footprint remains legible when the camera lowers the foreground wall. It is intentionally authored as a single two-tile utility object; simulation footprint and laundry capability remain unchanged.
