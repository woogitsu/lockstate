# Bedrock terrain concept v1

Original four-view image generated with the built-in image tool on 2026-09-24.
The sheet guides the Blender model; it is not a runtime texture.

The top-down panel sets the silhouette and plate scale. The oblique panel
shows shallow layered bevels. The detail panel guides fine fractures, while
the final panel checks readability beside dirt and concrete at game scale.
The asset should remain seamless on all four edges and distinct from gravel.

Prompt: Create a single original 2x2 concept sheet for a 1x1 bedrock terrain
tile in an overhead prison management game. Top view, 3/4 oblique view,
close-up slate stone structure, and game scale next to dirt and concrete.
Layered blue-gray stone plates, restrained cracks, soft bevels, subtle natural
variation, seamless tile edges, strong readability at 64 pixels. No copied
assets, no text, no UI, no people, no watermark.
