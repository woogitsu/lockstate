# Infirmary floor, visual revision 1

`infirmary-floor-multiview-v1.png` is an original four-view concept generated
with Codex image generation on 2026-09-24. It is a reference for the Blender
model, never a runtime sprite. The medical bed's pale enamel and teal fabric
set the adjacent material palette. The top, oblique, detail and repeat views
show a pale cool-grey hygienic sheet vinyl with restrained teal-grey mineral
flecks. The generated repeat has visible square seams; the production material
uses a continuous sheet instead, because repeating a seam on every game tile
would create a distracting grid in a 4×4 Infirmary.

The Blender model for `floor.infirmary.vinyl` has a seamless, fully opaque 1×1
tile. Its shallow satin finish and low-contrast flecks should separate the
Infirmary from institutional linoleum, laundry aggregate and shower ceramic
without competing with room names or furniture at zoom 0.5. No crosses, icons,
drains, or per-tile seam are drawn into the floor.

Concept prompt: One 2×2 four-view material sheet for the same original medical
sheet-vinyl surface: orthographic top, low oblique view, macro flecks, and a
3×3 repeat. Pale cool-grey hygienic vinyl with subtle teal-grey mineral flecks,
fine heat-welded seams in the concept, warm upper-left key and cool upper-right
fill. Restrained modern institutional style. No lettering, people, furniture,
walls, symbols, logos or UI. The generated image is reference only; Blender
5.2.1 authors the published tile.
