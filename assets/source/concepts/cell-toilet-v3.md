# Cell toilet refinement — 2026-09-24

`cell-toilet-multiview-v3.png` is an original generated modelling reference. The built-in image generator did not expose its backend model version, so this record makes no model-version claim. The sheet gives matched overhead, front, side and oblique views of one compact institutional toilet. It was not shipped as a game sprite.

The Blender scene follows the overhead silhouette: warm glazed porcelain, an oval raised seat with a dark recessed bowl, still blue-grey water, a compact rear cistern, a visible flush button, teal ceramic trim and a separate metal supply pipe. A subtle procedural noise node breaks up the porcelain. The geometry stays in the historical `fixture.cell.toilet_sink` collection so the published asset ID and the buildable 1×1 `object.toilet` mapping stay stable. The old combined fixture name is historical; the current game object is a toilet, not a separate buildable sink.

The reference depicts design intent, not a copied game asset. The Blender render remains the source of runtime pixels, with the repository's orthographic overhead camera and deterministic encoder.
