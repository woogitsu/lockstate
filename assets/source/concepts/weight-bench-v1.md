# Deferred yard exercise-bench concept

`weight-bench-multiview-v1.png` is an original four-view concept reference,
generated with the built-in imagegen tool on 2026-09-24. It is preserved for a
later gameplay decision and is not a published sprite or a Blender source
model in this branch.

Prompt: Original four-view industrial product concept sheet for a compact
strength-training bench in a top-down prison management game. Overhead, front,
side and three-quarter views of the same object. Fixed bolted steel frame,
blue-grey padded bench, short bar with small plates, amber safety stops, 2x1
tile footprint, neutral studio background. Readable at 64 pixels per tile. No
people, text, interface, logos or imitation of another game's artwork.

The current object catalogue has no exercise bench. Adding a player-buildable
one would change the rule that every buildable object fulfills a room
requirement, or impose a new requirement on a room. Neither gameplay decision
is part of this guard-art refinement.
