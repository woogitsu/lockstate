# Prisoner actor refinement

Original front, back, left and right reference: `prisoner-actor-refinement-v3.png`.

The reference explores a humane, tapered orange workwear silhouette with a pale chest ID. The current Blender source already has the tapered clothing, short hair, face and walk cycle from the earlier actor pass. This iteration carries only the larger pale chest ID into the production model. The four-view concept is a shape reference, not an atlas source: the Blender pipeline remains responsible for all eight directional rows and eight walk frames.

The displayed actor is about one quarter of the 256 px source frame at the ordinary 64 px tile scale. Fine folds and labels from the concept would not survive that reduction, so no text was copied onto the ID patch.
