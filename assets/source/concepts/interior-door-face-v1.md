# Interior door front elevation, visual revision 1

`interior-door-face-multiview-v1.png` is an original four-view reference generated with OpenAI image generation on 2026-09-24: front elevation, true overhead, oblique view and repeated modules. It guided the closed walnut leaf, two recessed panels, galvanized steel jambs, hinges and handle.

The playable `door.interior.face` sprite is authored in Blender as a shallow elevation relief in `environment.mvp.catalog.blend`; the concept PNG is reference only. Its walnut and steel palette matches the existing `door.interior.variants` overhead cap. The 1 × 1 frame has zero transparent margin and fills the wall opening in the game's 2D projection. Door simulation and placement remain unchanged.
