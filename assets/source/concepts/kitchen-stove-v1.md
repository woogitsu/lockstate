# Kitchen stove, visual revision 1

`kitchen-stove-multiview-v1.png` is an original four-view reference for a
commercial four-burner cooker. The overhead view controls the 2 × 1 tile
silhouette: four dark burner discs, a steel rim and a rear splash guard remain
separate at game scale. Oblique views guide the oven doors, knobs and feet.

The published sprite comes from the `furniture.kitchen.stove` collection in
`environment.mvp.catalog.blend`, not from the generated reference image. It
replaces the colour fallback for `object.stove` without changing cooking rules.
