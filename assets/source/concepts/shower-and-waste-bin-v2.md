# Institutional fixture concepts, revision 2

The two four-view concept sheets were generated with the Codex image-generation tool on 2026-09-23, using the owner's Prison Architect screenshots as a visual direction. The tool does not expose its underlying model version. The sheets are visual references for the Blender geometry; the shipped game art is rendered from `assets/source/blender/environment.mvp.catalog.blend`.

- `shower-head-multiview-v2.png`: worn wall-mounted institutional shower, bolted plate, exposed pipe and elbow, broad perforated metal head; top, three-quarter, front and side views. The Blender mesh separates the mounting plate, arm, collar, recessed nozzle face and rolled rim so the object reads at one tile.
- `waste-bin-multiview-v2.png`: galvanized open pedal bin, dark cavity, rolled rim, raised hinged lid and foot pedal; top, three-quarter, front and side views. The Blender mesh keeps its opening and its lid visible from directly above.

These are original generated concepts and do not copy any game asset or interface element from the screenshots.
