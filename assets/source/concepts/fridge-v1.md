# Kitchen refrigerator, visual revision 1

`fridge-multiview-v1.png` is an original four-view reference generated for
Lockstate: true overhead plus three coherent oblique views of one upright
institutional refrigerator. The overhead view establishes a blue-grey steel
roof and broad cream front cap; the oblique views guide the insulated door,
freezer division, pull, plinth and feet.

The shipped image is rendered from the 1 × 1 tile
`furniture.kitchen.fridge` collection in
`assets/source/blender/environment.mvp.catalog.blend`. The generated reference
is never used as a runtime sprite. The model changes only the appearance of
`object.fridge`, keeping its construction and food-storage rules.
